# WebTech FaceID

Hikvision yuz tanish turniketlarini boshqarish dasturi (Windows).

## Yuklab olish

**[WebTechFaceID-Setup.exe](https://github.com/Isroil97/webtech-faceid/releases/latest/download/WebTechFaceID-Setup.exe)** — har doim eng so'nggi versiya.

O'rnatish ustasi: dastur haqida → o'rnatish joyi → litsenziya kaliti → tayyor.
Dastur WebTech bergan litsenziya kalitisiz ishlamaydi.

O'rnatilgan dastur yangi versiyalarni o'zi tekshiradi va bitta tugma bilan yangilanadi.
